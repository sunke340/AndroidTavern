# 视觉方向探索（2026-11-22）

用户反馈"UI 与动效简陋"，先出静态样张选方向，再落地代码。

- `mock.html` / `mock-{A,B,C}.html`：三个方向的 HTML 样张（手机尺寸 360×760）
- `out/*.png`：截图（浏览器 1280×909，含说明文字）

| 方向 | 特征 | 适合 |
|---|---|---|
| A 静纸 | 无卡片无阴影、细线分隔、靠字号分层 | 阅读型长文本、最克制 |
| B 软卡 | 圆角卡片 + 轻阴影 + 实心药丸按钮 | 角色卡/游戏感，落地成本最低 |
| C 墨密 | 深色优先、高密度、行分隔线 | 长时间聊天 |

这些是**沟通用的近似图**，不是像素级设计稿；落地到 Compose 后字体与阴影会有差异，
以真机为准。样张里没有引入任何第三方 UI 库，全部是 Material 3 能表达的效果。

生成方式：改 `mock.html` → `python3 -m http.server 8765` → 浏览器截图。

## 应用图标（2026-11-22 定）

用户给了两张同款插画（白猫日光 / 黑猫月色），**选深色那张**作图标：

- 48dp 下轮廓仍清楚（深底 + 亮月亮/气泡形成对比）；浅色版细节会糊在一起
- 在浅色/深色桌面壁纸上都站得住；浅绿版在白底启动器上几乎融掉
- 深夜使用的场景更贴

实现（**踩过一次坑**）：

- adaptive icon 的画布是 108dp，但系统**只显示中央约 72dp**（外圈 18dp 留给视差裁剪）。
  第一版把插画满幅铺进去，气泡、啤酒杯、吧台全被切掉 —— 用户一眼就看到了。
- 现在前景层把插画缩到 **108dp 的 63%** 居中（落在 72dp 安全区以内），
  背景层用**整幅插画高斯模糊 + 压暗**，填补四周，避免出现方形接缝。
- 另出 5 档传统 mipmap（圆角方形，22% 圆角）给个别老启动器；那些不做遮罩，保持满幅。
- 对照图：`icon/preview-safe-zone.png`（100/72/66/63/60% 在 72dp 圆遮罩下的效果）、
  `icon/preview-final.png`（最终两层合成的样子）。

源图与圈形遮罩对照图在本目录：`icon/source-*.{jpg,webp}`、`icon/preview-circle.png`。

## 最终决定（2026-11-22）

- **方向 C · Dense Ink**：细线分隔、1px 描边、无阴影卡片；64dp 列表行；聊天用气泡。
- **主题墨紫**（从四个候选里选的"4 · Ink Violet"）：浅色主色 `#6D4BC4`，深色 `#C6B4F5`，
  用户气泡 `#E9E1FA`（保留紫调）。四套色板顺序：墨紫（默认）→ 森林绿 → 暖棕 → 石墨蓝。
  2026-11-22 调过一轮：原浅色主色 `#3B2E52` 明度过低，铺到白底上（底栏选中态、SegmentedRow 选中块）
  看着是黑灰、认不出紫，换成中明度紫罗兰；深色主色同步提亮到 `#C6B4F5`。
- 外观页的选项一律用 `SegmentedRow`（等宽铺满），不再用 FilterChip。
