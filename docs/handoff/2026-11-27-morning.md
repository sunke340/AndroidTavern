## 五、这一批踩的坑（都写进过 CI 失败里）

1. **不要在没有真机/回滚路径时改 DB 迁移**：群聊卡在这一步是**故意的**。迁移写错=启动崩+聊天记录可能读不出来。
2. **`str.replace` 的锚点会撞车**：`Regex("正则"), Preset("预设")` 在两个枚举里都出现，
   改一处只命中第一个 → 重复项 + 缺项，连锁 8 个编译错误。改枚举要带 `count(old)==1` 断言、逐个文件改。
3. **缺 import 只能 CI 抓**：这一批废了 5 次 CI（`Surface` / `Persona` / `AuthorNote` / `LocalContext` /
   `boundsInWindow`）。新写 Composable 就顺手扫一遍用到的符号。
4. **KDoc + `@Composable` 会被"插到前一个函数头上"** → `This annotation is not repeatable`。
5. **shell 里 `git commit -m` 带反引号会炸**（`pathspec '→' did not match`）→ 一律写消息文件 `git commit -F`。
6. **Android 模块的测试报告在 `build/test-results/testDebugUnitTest/`**，`check-tests-ran.sh` 原来只扫
   `test/` → 给 `:data` 加测试会被误判成"一个都没跑"。已修（并加了"没有 build/ 才算没跑"的 SKIP）。
7. **群聊夹具要"点进去"，不能调 `openGroupChat()`**：headless 里会挂死；正确路径是
   `getCharacters()`（才会 `getGroups()`）→ 开右侧抽屉 `#rightNavDrawerIcon` → 关掉 Welcome 弹窗 →
   点 `.group_select`。细节在 [fixtures.md §4.6](../dev/fixtures.md)。
