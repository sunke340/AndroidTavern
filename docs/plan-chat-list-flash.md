## 二、三类机制（所有现象都能归到这三条）

### M1 空间瞬时收放

LazyColumn 的条目高度变化在**一帧内**完成：`placementSpec = null` 是刻意关掉的
（串流时列表每帧长高，位移动画会重放 → 整屏抽动）。于是：

- 重新生成把最后一条从 transcript 删掉 → 底部锚点意味着那一屏高度**立刻被抽走**，历史瞬移；
- 继续/发送插入新条目同理（方向相反）。

日志里那些 2520 / 2940 / 3850px 的气泡说明这不是几像素，而是**整屏级**位移。

### M2 锚点语义 + 瞬时滚动

稳定 key（v161 为"整屏闪"加的）让 LazyColumn **锚住原来那条**（保护阅读位置），
新条目被放到视口外。所以：

- 流式气泡出现**不改变 `transcript.size`** → v164 的"按条数回底"根本不触发 → AI 气泡不跟底；
- 就算触发，`scrollToItem(0)` 是**瞬时**的 → "先错位再瞬移" = 闪。

### M3 交接（流式条目 ↔ 落库条目）

流式气泡是 `item(key="stream")`，落库后是 `key="msg-N"` 的另一个条目 ——
一帧内"删一个 + 加一个"。叠加三件事：

- 高度差：落库后多出动作行 34dp（重新生成还多版本条 40dp），v164 用 `Spacer` 占位缓解；
- `graphicsLayer.translationY` 的追高余量在 `isStreaming=false` 时**直接归零**（日志 22–140px）；
- 新条目重新组合 + 长文本重新跑显示正则/`InlineMarkup`（长消息上是几十 ms）。

## 三、用户两个想法的结论

### 想法一：AI 出首字母前先出气泡（显示"生成中"）+ 动画滚到底

**有价值，但不是"解锁串流期间开位移动画"的钥匙。**

- 串流阶段仍然不能开位移动画：文本每帧长高，它上面的条目每帧位移，`placementSpec`
  会每帧重放、被下一帧打断 → 持续抖动。这跟"气泡是不是提前建好"无关；
- 它真正的价值：把"气泡出现 + 滚到底"从**连续阶段**切成**离散事件**，这两件事可以动画；
- **前提（比动画更重要）**：占位气泡必须就是"将来那条消息"的同一个 item ——
  key = 将来的 `msg-N`、走同一个渲染入口。否则落库时还是"删+加"，动画救不了；
- **两条硬约束**：
  1. 占位气泡**不能进 `transcript`**（审计 P1-5：transcript 下标 ↔ DB 行号强耦合，
     删除/撤回/swipe 全靠这个 1:1），必须是 UI 侧的 pending 行，落库那一步才 append；
  2. 失败 / 0 字停止要能干净撤掉（那次移除应该带动画）。

### 想法二：重新生成时把旧气泡文本换成"重新生成中"

**能去掉"删条目"，但去不掉"高度突变"。**

2520px 的文本换成一个 80px 的"重新生成中"，一帧内整段历史会**下移 2400px** ——
位移量和删掉它完全一样，只是从"消失"变成"骤缩"。要真正消掉，必须让高度变化本身是动画：

| 做法 | 观感 | 代价 |
|---|---|---|
| A. 旧文本保留 + 盖"重新生成中"，新文本完整后替换 | 看不到进展，安静 | 用户不知道模型在写什么 |
| **B. 就地替换成流式文本 + 该 item 开 `animateContentSize`** | 开场平滑收缩，之后照常串流 | 要防两套动画叠加（跟随逻辑的 `translationY` 也在动） |
| C. 现状（删旧条目 + 新建流式条目） | 两处突变 | — |

推荐 **B**：条目身份不变（不删不加），高度用内容动画过渡；语义上也更接近原版
（旧版本始终在列表里，写完被新文本替换）。

## 四、目标架构（一批做完）

1. **行模型**：所有消息（pending / streaming / 定稿）走**同一个** `items(key=…)` 入口，
   key = 该消息的 transcript 下标（占位行用它将来的下标）。这样"流式 → 落库"只是数据变化，
   没有条目增删。
2. **发送 / 继续**：先插入占位气泡（"生成中"）→ `animateScrollToItem(0)` → 首 token 后原地生长。
3. **重新生成**：不删条目，就地替换成流式文本 + `animateContentSize`（方案 B）。
4. **动画边界**（硬约束）：

   | 事件 | 现在 | 目标 |
   |---|---|---|
   | 发送/继续 → 新气泡出现 | 瞬时 | 插入 + 动画滚到底 |
   | 首 token | — | 占位气泡原地开始长（无条目变更） |
   | 串流逐字 | `translationY` 跟随 | 保持，**不开 placement** |
   | 落库 | 删 + 加 + 高度差 | 同一条目内容定稿，无动画 |
   | 重新生成 | 删大条目 | 同一条目就地替换 + 高度动画 |
   | 撤回 / 删除 | 瞬时 | 位移动画 + 回底 |

## 五、开工前需要拍板的两点
