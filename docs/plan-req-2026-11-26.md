## 三、实现要点（省得重想）

- **1**：`Style.kt` 的 `rememberPressTint` 是唯一入口（行 / 卡 / 底栏共用）。改这里等于三处一起修；
  别再给某处单独加动画，手感会分叉。
- **3**：按钮放在 `bottomOverlay` 的 `Column` 里、在 `ChatInputBar` **之上**；列表底部让位读的是
  输入栏自己的实测高度，所以按钮出现/消失不会改变让位。点击走 `listState.animateScrollToItem(0)`
  （反排列表，0 就是视觉最底部）。
- **5**：`ChatInputBar` 用 `snapshotFlow { ime.getBottom(density) }` 判断"高度在下降" → `imeHiding`；
  `expanded = keepExpanded || (focused && (imeVisible || 有字) && !imeHiding)`。
  注意 `density` 与 `ime` 都要在组合里取好再进 `snapshotFlow`（那里不能读 CompositionLocal）。
- **6**：数据三层都接：`ConfigOverride.bubbleFontSize`（会话/卡，null = 跟随）、
  `AppSettings.bubbleFontSize` + `UiAppearance.bubbleFontSize`（全局，首帧就要用）；
  生效值只有 `UiState.effectiveBubbleFontSize` 一个出口；`ConfigKind.FontSize` 是会话级入口。
- **7**：新增 `Destination.PresetPrompt`（depth 3）+ `UiState.presetPromptDetail`；
  页面是 `PresetPromptScreen`，和「条目全文」同一形态。预设编辑页的行改成"外层拖拽 + 内层 clickable"，
  长按仍然起拖。
- **M16**：卡内嵌书列表的 `LazyListState` 提到 `MainScreen`（和全局书条目页同一套），
  换卡时才 `scrollToItem(0)`。
