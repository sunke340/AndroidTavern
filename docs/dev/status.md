- **语音输入**：真机有识别服务、没识别界面（`服务=1 意图=0`）。若机内识别也不可用，
  这台 ROM 的引擎可能需要联网/登录 —— 下一轮日志定，别猜。

- 顶层确认框的底片靠页面登记（`PageGlass`），转场期间谁最后登记没验过。
- `launchMode=singleTask` 改的是返回栈行为，只在分享路径上验过。

  超长气泡不能整段一个节点；覆盖保存卡无备份；折叠屏/分屏下胶囊菜单落点没验。
