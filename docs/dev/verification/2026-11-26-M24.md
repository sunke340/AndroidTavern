**这一批改了什么**（设计见 [plan-chat-list-flash-r2.md](../../plan-chat-list-flash-r2.md) §10 的 P1）：
把"消息"从 `List<ChatMessage>` + 三个并列的流式字段，换成一份行模型
（`ChatRow(uiKey, role, content, dbId)` + `Inflight(roundId, sessionId, uiKey, targetDbId, text, removed)`）；
渲染收敛成**一个入口** `itemsIndexed(key = uiKey)`；删除 / 撤回 / 翻版本改成按 `uiKey` 定位、按 `dbId` 落库。

**本批验收口径（零回归）**：正常**布局、尺寸、条目顺序、滚动位置、既有功能**无回归。
**允许**出现的变化只有一种：旧的错误行为被修掉（落库那一帧不再换条目、删一条不再让整列重播淡入）——
看到这类"变稳了"要记下来，但要与"引入回归"区分开。

> 判据：`tag=chat` 的收尾行 + 目视对比 v165。**本批不修**"AI 气泡不跟底"（那是 P2），
> 也不改占位文案、回底方式、动画边界（P2/P3/P4）——所以这些地方**应当与 v165 完全一样**。
