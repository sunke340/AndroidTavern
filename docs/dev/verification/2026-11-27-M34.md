## 一、切输入法语言时输入区被收回（新 bug）

**根因**：输入区展开的判据里有"键盘正在收起"（`imeHiding`）。它的判法是"这一帧的 IME 高度比上一帧小"——
而英文切中文时，输入法的候选栏会让键盘高度**变一点点**，于是被判成"开始收键盘"，输入区缩回一行，
左下模型钮跟着淡出（它的可见性是展开态的 alpha）。

**修法**：改成"掉到峰值高度的一半以下"才算收起。真的收键盘会一路掉到 0；切输入法/切语言只是换一档高度。
日志多了两行：`键盘开始收起 高=… 峰值=…` / `键盘回来了 高=… 峰值=…`。

| # | 怎么造 | 过 = 看到什么 |
|---|---|---|
| 1 | 点输入框弹键盘，切到中文输入法 | 输入区**保持展开**、左下模型钮**还在**；键盘只是变高/换候选栏 |
| 2 | 再切回英文 | 同上，不缩 |
| 3 | 按返回键收键盘 | 输入区正常缩回一行（这条不能因为改了判据而失效） |
| 4 | 收键盘后再点输入框 | 键盘回来、输入区展开 |
| 5 | 看日志 | 切输入法时**不该**出现 `键盘开始收起`；按返回键时应当出现 |

## 二、分享导入的确认框（第三次修）

前两次的日志说明：确认框**确实被弹了**（`确认框显示：导入这张卡？`），但一个进程里
`nav tabs depth=0 init` 出现了 3 次 —— 每分享一次就**新建一个 MainActivity 实例**叠在旧实例上
（默认 `launchMode=standard`），确认框弹在新实例里，而用户看的是旧实例。

**修法**：`MainActivity` 改 `launchMode="singleTask"` —— 分享走 `onNewIntent` 进同一个实例，
确认框和界面在同一个窗口。

| # | 怎么造 | 过 = 看到什么 |
|---|---|---|
| 6 | 文件管理器「分享」测试卡 PNG → 本 App | 切到本 App 后**立刻**看到玻璃确认框「导入这张卡？」，背景变暗 |
| 7 | 点「取消」 | 什么都不发生；日志 `确认框取消：导入这张卡？` + `分享导入：已取消` |
| 8 | 再分享一次，点「导入」 | 导入并落到角色详情；日志 `分享导入：已确认` |
| 9 | 看日志 | `nav tabs depth=0 init` **只出现一次**（整份日志里），不再是每分享一次多一条 |

## 三、人设的位置（这条是"对，但看不见名字"）

把 v184 的请求逐条对过了，顺序是**对的**：

```
[system] 下雨天她会多烧一壶水…        ← worldInfoBefore（世界书 before 段）
[system] 一个神秘的人                 ← personaDescription（**这就是你的 6 字人设描述**）
[system] 山脚书铺的掌柜…              ← charDescription
[system] 温和、话不多…                ← charPersonality
```

**名字（卡尔）不会单独出现在请求里** —— 原版里它只用来展开 `{{user}}`（你贴的这段里没有 `{{user}}`，
所以看不到）。这不是漏发。

这一版只加了一行可见性：「查看本次请求」的首行参数多了 `人设=卡尔(描述=6字)`，不用翻日志就能确认。

| # | 怎么造 | 过 |
|---|---|---|
| 10 | 发一条，打开「查看本次请求」 | 首行末尾有 `人设=卡尔(描述=6字)`；正文里那条独立 `[system]` 就是描述 |
| 11 | 把某个提示词里写 `{{user}}` | 它被展开成 `卡尔`（这才是人设名的用法） |
