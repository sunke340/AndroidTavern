# M26 · 2026-11-26 · v168：P3 重新生成就地替换 + 平滑收缩

**装包**：**`artifacts/app-v169-87e5b56.apk`**（v168 `e37ded3` 那版收缩不合格，作废）。
BUILD_ID 已验 = `87e5b5620494dae72456687edd19aa570a69e5e6`（`classes17.dex`），签名 `55:E0:C6:…:0B:E7` 一致。

**这一批改了什么**（口径：[r2 §13.1](../../plan-chat-list-flash-r2.md)）：

- **就地替换**：重新生成不再"把旧行从列表里撤掉、收尾再追加一条新行"，而是**同一行改写**
  ——`inflight` 直接用那条消息原来的 `uiKey`（`m{dbId}`），收尾按原行号 `replaceMessage`。
  界面上自始至终是同一个 LazyColumn 条目，所以开场不换条目、不重播淡入、不重排长文本。
  顺手删掉 P0/P1 的四个适配器：`ReplaceTarget` / `GenerationRound.removedContent` /
  `Inflight.removed` / `RowAction.RestoreRemoved`（0 字停止与保存失败现在都只是"不写行"，
  旧正文原地不动），以及 `UiState.streamingRegenerate`。
- **平滑收缩**：点「重新生成」后气泡**从下沿一点点收下去** —— 旧正文留在气泡里被高度裁掉
  （380ms、`Motion.Standard`），上面的消息滑着让位；窗口走完才换成 `重新生成中` + 呼吸点，
  首字到了再长出新正文。高度是**显式驱动**的（`Modifier.height(h)` + `Animatable`）：
  `animateContentSize` 只动画"报给父级的尺寸"，气泡自己不会变小（v168 第一版就栽在这）。
  严格按 r2 的四条硬约束：C1 高度显式驱动、只在窗口期挂；C2 窗口里的 token 只攒不推；
  C3 窗口里桥接三件套全关（`translationY` / `dispatchRawDelta` / 追平滑高度）；
  C4 0 字停止与保存失败时旧正文**涨回来**也走同一条动画，窗口等收尾落地之后才关。
- 减动效（系统「移除动画」）时收缩退成瞬切，窗口时长不变。
- **收尾涨回**：0 字停止 / 失败时，如果收缩早已走完、界面停在占位上，收尾会**补开一个涨回窗口**
  （起点是占位高度、终点是收缩前的高度），旧正文从占位那个高度一点点长回来。

**这一批不包含**：P4 的动画收口（`prevKeys` 入场规则、`placementSpec` 只挂非串流、
落库前 `smoothHeight` snap、删除/撤回的位移动画）。
