**回执**：待验。
**装包**：`artifacts/app-v161-410a713.apk`（tag `apk-m192`）。

**改了什么**（M17 真机回执的三条，口径见 [pitfalls.md](../pitfalls.md) 的对应条目）：

- 停止生成现在知道"这一轮是重新生成 / 继续"：半截内容不再被当成一条**新消息**追加，
  于是「继续」撤下去的那条也不会丢（以前要退出会话重进才恢复）；
- 打断之后的「重新生成」不再拿**上一条消息**的 swipe 底本：被打断的那条本身成为 1/N，
  新结果是 2/N，能翻回去；
- 聊天列表改成按"原 transcript 下标"做 key：追加消息只让新气泡淡入，不再整屏换槽位闪一下；
- 「查看本次请求」首行补上 model 与采样五项（真机上验三级采样的唯一界面证据）。
