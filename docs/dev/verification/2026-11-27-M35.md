# M35 · 2026-11-27 傍晚：导入后详情空白 / 确认框材质 / 语音输入接入

> 装 `apk-m227`。三条改动 + 一条新能力。
>
> 口径：[pitfalls「导入后详情页没有开场白」](../pitfalls.md)、
> [pitfalls「顶层浮层没有底片」](../pitfalls.md)。

## 一、导入后详情页要立刻是对的

**根因**：`importCard` 只写了 `detailCardId`，没走"打开详情"（日志里那次 push 没有 `读详情`），
页面拿到的是上一次的 `detail` → 开场白/内嵌书全空；重进才有。

| # | 怎么造 | 过 = 看到什么 |
|---|---|---|
| 1 | 分享测试卡 → 确认导入 | 进详情页后**立刻**有：开场白（含多条时的 `‹ N/M ›`）、「会话」tab 的会话数、「世界书」tab 的内嵌条目数 |
| 2 | 看日志 | 导入成功之后应当紧跟一行 `读详情 <id> Nms 条目=…` |
| 3 | 连续导入两张不同的卡 | 第二张的详情**不是**第一张的内容（开场白、条目数都跟着换） |

## 二、分享确认框要用液态玻璃

**根因**：它挂在 `MainScreen` 最外层（为了在上一个实例也能看见），拿不到页面录的底片，只能画成纯色板。
现在页面骨架把底片登记给顶层（`PageGlass`）。

| # | 怎么造 | 过 = 看到什么 |
|---|---|---|
| 4 | 分享 → 确认框弹出来 | 板子背后的正文是**糊的**（能看出有内容、但认不出字），边缘有折射；不是一块灰板 |
| 5 | 看日志 | 出现 `glass 液态档 … 着色器=true`（`false` 就是又退回色板了） |
| 6 | 在聊天页分享（此时底下是聊天页） | 同上，糊的是聊天内容 —— 说明底片跟着**当前页**走 |

## 三、语音输入（App 内直连 + 麦克风权限）

这台机器 `服务=1 意图=0`（有识别引擎、没有系统识别界面），所以走 App 内的 `SpeechRecognizer`。

| # | 怎么造 | 过 = 看到什么 |
|---|---|---|
| 7 | 聊天页 ⋮ →「语音输入」（第一次） | 弹**麦克风权限**申请 |
| 8 | 选「允许」后说一句话 | 输入框里出现识别文字（边说边出中间结果），说完定稿 |
| 9 | 选「拒绝」 | 提示"需要麦克风权限才能语音输入"；**入口还在**，再点会再申请一次 |
| 10 | 允许后什么都不说，等它超时 | 提示"没听清，再说一次"，不卡住 |
| 11 | 听着的时候退出聊天页 | 不再有回调写输入框（识别器已销毁） |
| 12 | 看日志 | `语音识别 可用=true 服务=1 意图=0`；`语音输入 N 字（App 内）`；出错时 `语音识别出错：<原因>` |

## 回执（v187，装 `apk-m227`）

| 项 | 结果 |
|---|---|
| §一 导入后详情 | ✅ 过（1、2 都对） |
| §二 确认框材质 | ✅ 过 |
| §三 语音输入 | 权限申请 ✅；允许后**报错**：`ui 语音识别出错：未知错误 11` |

**11 = `SpeechRecognizer.ERROR_SERVER_DISCONNECTED`**（识别服务与服务端断开）。时间线：
`16:31:05.946 麦克风权限：已允许` → `16:31:21.653 语音识别出错：未知错误 11`，
中间 15.7 秒 —— 引擎是在听的，最后服务端那一步掉了。

`apk-m228` 针对这条改了四处：

1. **机内识别优先**：API 31+ 且 `isOnDeviceRecognitionAvailable` 为真时用
   `createOnDeviceSpeechRecognizer` + `EXTRA_PREFER_OFFLINE` —— 不连服务端就不可能服断；
2. 错误码 11–14 补了名字（服断 / 语言不支持 / 语言包没装 / 无法检查语言支持）；
3. **服断/网络类错误自动重试一次**（只一次，别让人等两回十几秒）；
4. 日志补 `机内=… 引擎=<包名>` 与 `语音识别：开始听（机内/服务端）`、`首个中间结果 N 字` ——
   下一轮就能判断是"引擎要求联网"还是"我们用法不对"。
