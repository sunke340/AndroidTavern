## M0 · 2026-11-22 · 首次真机跑通

**APK**：`app-debug`（CI 出包，release `apk-latest`），约 11 MB，minSdk 26。
**链路**：PNG 卡（assets）→ `PngCard` → `CharacterCard` → `PromptBuilder` → `OpenAiCompatibleClient` → SSE 流式 → Compose 显示。
**provider**：OpenAI 兼容端点（用户填 baseUrl / key / model）。

### 结果：通过

| 检查项 | 证据 |
|---|---|
| 安装、启动 | 界面正常显示 |
| 卡片解析 | 状态行显示描述字数；「看请求」里出现完整描述 |
| 提示词组装 | 「看请求」显示 4 段：`main` → 描述（含 `[Seraphina's Personality= ...]`、`<START>`、示例对话）→ … |
| 请求发出 | 状态行 `完成（finish_reason=stop）` |
| 流式显示 | 回复逐字出现（用户确认） |
| 角色一致性 | 回复自称"塞拉菲娜，这片魔法森林——艾尔多利亚的守护者"，提到粉发、琥珀眼、治愈魔法、被野兽追赶——**全部来自卡里，不是模型自己编的** |

### 顺带确认的两个行为

1. 这张卡的 `description` **内含** `<START>` 与示例对话；原版把整个 description 当成一条 system 消息发出去，
   不做示例解析。我们照抄——「看请求」里能看到它原样在里面。
2. 用户用中文提问、卡是英文时，模型用中文回。这是模型行为（跟用户语言走），不是我们注入的语言指令。

### 这一轮暴露的问题

- CI 每次重新生成 debug keystore → 每次装新版都得先卸载（签名不一致）。待做：固定 debug 签名。
- `:core:ai` / `:core:card-format` 的公开 API 暴露了 `implementation` 依赖的类型
  （`OkHttpClient`、`JsonObject`），本机编不出来，只有 `:app` 会报 `Cannot access class X`。已修。

## M1 · 2026-11-22 夜 · 待真机验收（夜间改完，早上验）

**改了什么**：固定 debug 签名（可覆盖安装）、SAF 导入自己的 PNG 卡、卡列表/记住选择、
会话与消息落 SQLite（杀进程能恢复）、会话列表（新建/切换/删除）、停止生成保留半截内容。

**装包前必看**：签名换了（旧包是 CI 临时签的），**这一次要卸载重装**；装完以后就可以直接覆盖安装了。

### 验收清单（按顺序做，每步都有"该看到什么"）

| # | 操作 | 该看到什么 | 没看到说明什么 |
|---|---|---|---|
| 1 | 标题下面那行小字 | 7 位 commit 短 sha（和 release 备注里的 commit 一致） | 装到的不是这次构建 |
| 2 | 设置 → 填 baseUrl / key / model → 发一句 | 流式回复，状态行 `完成（finish_reason=stop）` | 网络/Key 问题，先看状态行 |
| 3 | 设置 → **导入 PNG 角色卡** → 选手机里的卡 | 状态行 `已导入：<卡名>`，卡列表多一行带"导入"标记，且自动切过去 | 说明选择器回来的 Uri 读不到，或那张 PNG 没有 `chara`/`ccv3` |
| 4 | 对着新卡聊一句 | 回复贴合卡设；「请求」里能看到那张卡的描述 | 导入成功但提示词没带上 → 把「请求」截图给我 |
| 5 | 杀进程 → 重开 | 自动回到刚才那个会话，消息都在；卡还是上次选的那张 | 会话没落库 / 冷启动恢复失败 |
| 6 | 会话 → **新建** → 说一句 → 切回旧会话 | 两个会话内容不串；旧会话消息原样 | 切会话时没重新载入 |
| 7 | 会话 → 删掉当前会话 | 自动落到下一个会话；消息数跟着变 | 级联删除没生效 |
| 8 | 生成中按**停止** | 已收到的内容留下成一条消息，重开还在 | 半截内容没落库 |
| 9 | 用一个新的 APK 直接覆盖安装 | 不提示"签名不一致"，不用卸载 | 签名没固定住 |

### 已知限制（不用报，都是没做）

- 首条 `first_mes` 不会自动作为开场白（原版会；缺 fixture，留到 P0-6）。
- 没有 swipe / 重新生成 / 编辑 / 删除单条消息。
- API Key 只在内存，杀进程就没了（下一步做 Keystore 存储）。
- 世界书、预设、token 计数都没有。
