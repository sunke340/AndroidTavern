# UI 地图与词表（`docs/ui-map.md`）

**这份文件解决一个问题**：用户说"某页面某个位置的那个东西"时，我们俩对不上。
这里给每个**页面、区域、材质、共用组件**一个能说的名字；代码标识只当副标。
持久规矩（取值、材质铁律）不在这里，在 [app/AGENTS.md](../app/AGENTS.md) 与
[docs/dev/pitfalls.md](dev/pitfalls.md)。

> 词汇量是有界的：**一级 3 个 tab + 12 个目的地 + 4 个详情标签 + 3 个卡配置页**，
> 区域约 12 个，值得命名、有唯一入口的组件约 35 个。不描述"每个页面的每个像素"。

---

## 一、使用协议：对不上就问，不猜

1. 用户描述若无法一一对应到本表的名字，**先列出我理解的 1–3 个候选**
   （`页面 → 区域 → 组件`），让用户点一个；**不许**在没确认前自造映射并动手。
2. 涉及**改动**（改代码 / 删数据 / 改配置）的必须等到确认；**只读**的查询可以先按最可能
   的读法继续，但回执第一行要写"我按 X 理解"。
3. 用户用的新叫法，只要以后还会用到，就当场加进本表**别名**列，下次不再问。
4. 回执只用本表的名字；要引入新词，先加表并让用户点头（不许在回执里临时造词）。
5. 位置词（"上面那个""右边那个"）只能在**同一区域内**区分组件，不能当标识；
   标识必须是 `页面 + 区域 + 组件` 三段。

## 二、维护规则（决定这份文件能活多久）

1. **名字必须能在代码里 grep 到**。`bash tools/check-ui-map.sh` 会查：表里反引号包着的
   代码标识必须在 `app/` `core/` `data/` 里真实存在（不许有幽灵名字）。
2. **枚举里的页面/标签必须都在本文件里**（同一个脚本查）。新增 `SettingsPage` /
   `CardConfigPage` / `DetailTab` 却没更新本文件，CI 直接红。
3. **出现第二次才命名**：某组合只在一处用 → 用"形状 + 能力"描述，不造名字；
   第二处也要用、且行为要一致 → 提升成组件并在这里登记（`WorldBookEntryRow` 就是这么来的）。
4. **新增/删除页面或关键组件，同一提交里改本文件**并跑两个脚本：

   ```bash
   bash tools/gen-ui-map.sh      # 打印从代码抽出的页面树/组件索引，照着改
   bash tools/check-ui-map.sh    # 校验没漂移
   ```

5. 名字以**用户认可的说法**为准；代码里确实难听的名字（如 `GroupPiece`）先并列标注，
   等有别的改动时顺带改名。

## 四、区域词表（专治"某位置"）

区域是**页面内部的固定分区**，任何页面的组件都落在这 12 个里：

| 区域 | 说明 |
|---|---|
| 页头 | 顶部固定条：返回钮 + 标题（+ 副标题） |
| 页头右上胶囊 | 页头右侧那枚圆形/胶囊动作钮（新建、导入、⋮） |
| 内容首项 | 滚动内容的第一项，与页头的间距是定死的（见下） |
| 列表组 | 一组行的外壳（圆角 + 分隔线） |
| 行 | 组里的一行 |
| 行尾开关 | 行右侧的开 / 关（独立布尔） |
| 勾选圈 | 行左侧的选中标记（"当前是哪一项"） |
| 气泡 | 聊天里的一条消息 |
| 气泡底下动作行 | 气泡下面那排图标（复制 / 重生成 / 撤回 …） |
| 输入胶囊 | 聊天页底部输入区，含左下模型钮与右下发送钮 |
| 底部抽屉 / 确认框 | 弹层：动作单、模型快捷抽屉；删除/覆盖确认 |
| 开场白翻页条 | `‹ N/M ›`：贴在开场白气泡下沿右侧 |
| 占位气泡 | 点发送 / 继续 / 重新生成之后、模型还没吐字时那个小气泡（不是真消息） |
| 呼吸点 | 占位气泡里那三个交错亮暗的圆点（删掉它不影响功能，但用户要它） |

**行系统怎么说话**（能力是参数，不是新模板）：

| 能说的名字 | 代码标识 | 是什么 |
|---|---|---|
| 可勾选的行 | `ListRow` + `ActiveMark` | 左侧勾选圈；整行点按 = 选中这一项 |
| 带行尾开关的行 | `ListRow` + `Switch` | 右侧独立开 / 关，不影响别的行 |
| 可拖的行 | `ListRow` + `longPressDraggableHandle` | 长按起拖（预设顺序页，整行可拖，不做抓手） |
| 可长按的行 | `ListRow` 的 `onLongClick` | 长按出抽屉（编辑 / 删除） |
| 抽屉动作行 | `SheetActionRow` | 抽屉里的一项，危险项为红字 |

> **勾选 ≠ 开关**：勾选回答"当前是哪一项"（左侧、互斥/多选）；开关回答"这一项自己开不开"
> （右侧、独立布尔）。两者代码里是两个东西，别叫混。

## 七、日志 tag（排障时说"哪条日志"用）
